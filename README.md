# Python Basics Notebook

A Jupyter notebook of beginner Python exercises from the start of my Generative AI learning program.

## Contents
1. **Hello World**: the first `print` statement.
2. **Simple Calculator**: a menu-driven calculator for `+`, `-`, `*` and `/` that reads user input and handles division by zero.
3. **Student Grade Calculator**: reads a mark from 0 to 100, validates it, and maps it to a grade from A to E.

## Run
```bash
pip install notebook
jupyter notebook hello.ipynb
```
Or open it in VS Code with the Jupyter extension. No other dependencies are needed.
